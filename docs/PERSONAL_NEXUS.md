# Personal Nexus Foundation

This phase contains personal Nexus only. Business/CRM, sales, calling, client/payment
workflows, website-business pipelines, domain/deployment automation, and Cloudflare
integration are intentionally deferred.

## One shared brain

Nexus remains one intelligence. Roles are capability/context profiles, not separate AIs.
The current personal roles are:

- personal: conversation, planning, general assistance, research, and authorized tools.
- research: evidence-based general research and verification.

The underlying model is replaceable. Nexus owns memory, planning, permissions, tools,
verification, learning, and self-improvement.

## Owner control

Consequential actions use an explicit approval request. "approve" resolves the currently
active request only. Sensitive actions can require a second factor. Voice or face
confidence is never treated as perfect authentication.

## Voice

Voice is an interface to the same Nexus brain, not another chatbot. The runtime supports
speaker, private/headphone, and silent modes. Wake-word, speech recognition, and text-to-
speech providers can be attached later.

## Vision

Vision is opt-in and privacy-first. Local processing is preferred where practical.
Camera observations do not independently authorize sensitive actions.

## Notifications

Events use a priority-aware queue. Desktop, phone, or wearable delivery can consume the
same notification objects later.

## Learning and self-improvement

Nexus can observe outcomes, evaluate them, research failures, and stage bounded
improvements. Live foundation promotion remains owner-controlled.

## Unlimited conversations

There is no artificial conversation-count limit, message-credit system, or premium gate.
Legitimate engineering safeguards remain for request size, retries, tool calls,
concurrency, external API spending, and hardware.

## Long-running work

Task execution should preserve state and resume rather than discard work merely because
one execution window ended. The existing task system remains the canonical place for
persistent task state.

## Deferred

Business/CRM, sales/calling workflows, client/payment/revenue workflows, business website
pipelines, domain/deployment automation, and Cloudflare are intentionally left for later.
